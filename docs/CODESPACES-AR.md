# التشغيل الخاص عبر GitHub Codespaces

هذا مسار تشغيل من المتصفح باستخدام حساب GitHub، دون ربط Railway أو أي استضافة أخرى. هو مناسب للاستخدام عند الحاجة؛ يتوقف Codespace عند إيقافه أو انتهاء مهلة الخمول، ولا يمثل استضافة إنتاج دائمة تعمل 24/7.

## ما الذي تم اختباره؟

- تثبيت جميع حزم المشروع مع TwelveLabs باستخدام `uv sync --frozen --all-extras`.
- نجاح 269 حالة اختبار محلية، مع تجاوز 3 اختبارات تعتمد على خدمات خارجية.
- فتح WebUI دون استثناءات عبر Streamlit AppTest مع تعطيل فحص التحديث الخارجي في الاختبار.
- إنشاء MP4 فعلي 1920×1080، مدة 6.53 ثانية، مع نص عربي صحيح وموسيقى؛ استخدم الاختبار مقطعاً اصطناعياً ووضع عدم التعليق الصوتي.
- نجاح بوابة Docker المقترحة في اختبار العمليات المحلي: رفض الدخول المجهول، وقبول الدخول الصحيح إلى WebUI وAPI، وفحص جاهزية الخدمتين.
- لم ينجح اتصال Edge TTS من بيئة الاختبار بسبب انتهاء المهلة. لا تزال مفاتيح مزودي النص والمواد والصوت المدفوع والنشر غير مهيأة.
- لم يتم إنشاء Codespace أو نشر خادم عام أو تشغيل Docker build الفعلي؛ يتطلب تأكيدها بيئة Codespaces أو Docker.

## إذا أضيفت الحزمة إلى المستودع

1. افتح [مستودع MoneyPrinterTurbo](https://github.com/maljasser/MoneyPrinterTurbo).
2. اختر **Code → Codespaces → Create codespace** على الفرع الذي أضيفت إليه الحزمة. ابدأ بـ4 أنوية وذاكرة 8 GB أو أعلى عند توافرها.
3. انتظر اكتمال التهيئة؛ تثبت الحزمة المتطلبات وتبدأ WebUI وAPI تلقائياً.
4. في تبويب **Ports**، تأكد أن `8501` و`8080` مضبوطتان على **Private**. لا تحولهما إلى Public؛ الحماية في هذا المسار تعتمد على تسجيل دخولك إلى GitHub.
5. افتح منفذ **8501** للتطبيق. للوصول إلى وثائق API افتح رابط منفذ **8080** وأضف `/docs`.
6. أدخل مفاتيح الخدمات من **Settings**. يكفي اختيار مزود نص واحد ومصدر مقاطع واحد للبدء بالتوليد الآلي؛ ويمكن استخدام نصوص ومقاطع محلية أيضاً.

إذا كان لديك Codespace سابق ثم أضفت ملفات التهيئة، اختر **Codespaces: Rebuild Container** لاعتمادها. تبقى بيانات المشروع ضمن مساحة عمل Codespace ما دام موجوداً؛ احفظ نسخة من الفيديوهات والإعدادات قبل حذفه.

## إذا تعذر رفع الحزمة من اتصال GitHub

ملف ZIP المرفق يحتوي على الملفات المعدلة داخل `files/` وعلى رقعة `changes.patch`، ولا يحتوي على مفاتيح أو على المستودع الكامل. التعديلات معدّة للإصدار ذي المعرّف الأساسي الموضح في `VALIDATION.md`.

يمكنك إنشاء Codespace عادي على مستودعك أولاً، ثم رفع `changes.patch` إلى جذر المشروع وتطبيقها من الطرفية. تحقق من عدم وجود تعديلات متعارضة؛ أمر `--check` يختبر التطبيق دون تعديل الملفات:

```bash
git apply --check changes.patch
git apply changes.patch
bash .devcontainer/setup.sh
bash .devcontainer/start.sh
```

إذا فشل فحص الرقعة، توقف عن تطبيقها لمعالجة الاختلاف بين الإصدارين؛ لا تستخدم الاستبدال القسري. لا تحتاج هذه الطريقة إلى تثبيت تطبيق خارجي في ChatGPT. ولإتاحة الحزمة تلقائياً في كل Codespace جديد، احفظ التعديلات على فرع في مستودعك لاحقاً.

## تفعيل باقي الميزات

تجد جدول المزودين والمفاتيح والوظائف في [دليل الميزات](PRIVATE-CLOUD-AR.md#تفعيل-الميزات). واجهة المشروع الأصلية إنجليزية في هذا الإعداد، مع صوت ومحتوى فيديو عربي؛ لم تُضف ترجمة عربية كاملة لشاشاته.

بعد تغيير مفاتيح الخدمات، أوقف Codespace وأعد تشغيله لاعتماد الإعدادات في WebUI وAPI معاً. اختبر فيديو قصيراً كاملاً بعد ربط المزودين قبل التشغيل الدفعي. تحتاج الميزات المدفوعة والنشر إلى حساباتك وإعداداتها الخاصة.

## التكلفة والخصوصية

يتضمن GitHub حصة استخدام شهرية للحسابات الشخصية. لا يعني ذلك أن Codespaces مجاني بلا حدود: احتساب وقت التشغيل يتناسب مع عدد الأنوية، والتخزين قد يستمر احتسابه عند إيقاف الجهاز. راجع الحصة المتبقية وميزانية الإنفاق في حسابك قبل الإنشاء. تُحتسب رسوم مزودي الذكاء الاصطناعي بصورة مستقلة.
