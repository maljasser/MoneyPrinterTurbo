# تشغيل MoneyPrinterTurbo برابط خاص

هذه الحزمة تجهّز التطبيق الحالي للاستخدام الفردي عبر رابط HTTPS محمي باسم مستخدم وكلمة مرور. تشمل WebUI وAPI وCLI وجميع حزم Python والإضافة الاختيارية TwelveLabs. لا تُنشئ حساب استضافة أو اشتراكات خارجية تلقائياً.

## إعداد الاستضافة

استخدم خدمة Docker واحدة، بنسخة تشغيل واحدة (Replica)، مع وحدة تخزين دائمة عند `/data`. نقطة بداية مقترحة: 4 vCPU و8 GB RAM؛ تتغير الحاجة بحسب مدة الفيديو ودقته وعدد المهام. هذا تقدير للتجهيز وليس سعراً أو ضماناً للأداء. لا يلزم GPU للمسارات السحابية المعتادة؛ يعمل Whisper على CPU وقد يستغرق وقتاً أطول.

في Railway:

1. اربط المستودع `maljasser/MoneyPrinterTurbo` والفرع الذي يحتوي على هذه الحزمة.
2. استخدم `deploy/Dockerfile`؛ عيّن `RAILWAY_DOCKERFILE_PATH=deploy/Dockerfile` مع بقاء جذر البناء في جذر المستودع.
3. أضف Volume عند `/data` قبل التشغيل. لا تكفي ملفات الحاوية المؤقتة.
4. أدخل متغيرات الدخول أدناه في إعدادات الخدمة الخاصة، ثم أنشئ نطاق HTTPS وحدد المنفذ `8080`.
5. اجعل فحص الجاهزية `/healthz` والمهلة 120 ثانية، وإعادة التشغيل عند الفشل، وعدد النسخ 1. أبقِ الخدمة قيد التشغيل أثناء إنشاء الفيديو.
6. افتح الرابط وسجّل الدخول. تتوفر وثائق API على المسار `/docs` تحت الرابط نفسه.

| المتغير | القيمة أو الغرض |
|---|---|
| `MPT_AUTH_USER` | اسم مستخدم خاص بك؛ حروف إنجليزية أو أرقام أو `_.@-` |
| `MPT_AUTH_PASSWORD_HASH` | تجزئة bcrypt لكلمة مرور قوية؛ ليست كلمة المرور نفسها |
| `RAILWAY_DOCKERFILE_PATH` | `deploy/Dockerfile` |
| `PORT` | `8080` |
| `MPT_DATA_DIR` | `/data`، مضبوط في صورة التشغيل |
| `MPT_CONFIG_FILE` | `/data/config.toml`، تضبطه حزمة التشغيل |

لتوليد التجزئة دون وضع كلمة المرور في سجل الأوامر، شغّل `caddy hash-password` وأدخل كلمة المرور عند طلبها. احتفظ بكلمة المرور في مدير كلمات المرور، وضع التجزئة في متغير الخدمة. لا تضع أياً منها في GitHub. تستخدم الحزمة HTTPS الذي توفره الاستضافة؛ لا تعرض بوابة HTTP مباشرة على الإنترنت.

بوابة الدخول تحمي الواجهة، الاتصالات الحية، الرفع والتنزيل، ملفات الفيديو وAPI. لا يُتاح دون تسجيل الدخول سوى `/healthz`، ويعرض نتيجة جاهزية مختصرة. يتحقق الفحص من خدمتي API وWebUI؛ يفشل التشغيل إذا لم تضبط بيانات الدخول أو لم تربط وحدة التخزين في Railway.

## تفعيل الميزات

اختر مزوّداً مناسباً لكل وظيفة. المزوّدون بدائل لبعضهم؛ لا تحتاج إلى الاشتراك في جميعهم. وجود خيار في الواجهة أو تثبيت مكتبته لا يعني صلاحية حسابه أو مفتاحه أو نجاح الاتصال به.

| الوظيفة | طريقة التفعيل | المرجع الرسمي |
|---|---|---|
| كتابة النص والكلمات المفتاحية | أدخل مفتاح OpenAI أو Gemini أو مزوّد آخر مدعوم في Settings؛ ويمكن إدخال نص جاهز | [إعدادات المشروع](../config.example.toml) |
| مقاطع جاهزة | أدخل مفتاح Pexels أو Pixabay أو Coverr؛ ويمكن رفع ملفاتك المحلية | [Pexels API](https://www.pexels.com/api/)، [Pixabay API](https://pixabay.com/api/docs/) |
| التعليق الصوتي | Edge TTS دون مفتاح، بشرط إمكان الاتصال بالخدمة؛ أو مفتاح مزوّد صوت آخر | [edge-tts](https://github.com/rany2/edge-tts)، [مزودو المشروع](../config.example.toml) |
| العربية | إعداد أولي للصوت السعودي `ar-SA-HamedNeural` وخط Noto Naskh Arabic للفيديو | [إعدادات الصوت](../app/services/voice.py) |
| الترجمة المكتوبة | توقيت Edge عند استخدامه أو Whisper عند اختياره صراحةً | [إعدادات Whisper](../config.example.toml) |
| الموسيقى | مكتبة المشروع أو ملف ترفعه؛ تتطلب Sonilo وElevenLabs بيانات خدماتهما | [إعدادات الموسيقى](../config.example.toml) |
| توليد صور أو مقاطع بالذكاء الاصطناعي | مفتاح مستقل لمزوّد المادة الذي تختاره؛ قد توجد رسوم لكل عملية | [مصادر المواد المدعومة](../config.example.toml) |
| تحليل الفيديو الدلالي | حزمة TwelveLabs مثبتة؛ أدخل مفتاح الحساب لتشغيل التحليل | [TwelveLabs](https://docs.twelvelabs.io/) |
| النشر على المنصات | حساب Upload-Post ومفتاح API وربط قنواتك، ثم تفعيل المنصات المطلوبة | [Upload-Post](https://docs.upload-post.com/) |

واجهة المشروع الأصلية لا تتضمن ترجمة عربية كاملة حالياً؛ تبدأ هذه الحزمة بالواجهة الإنجليزية وإعدادات محتوى عربية. لا تتضمن هذه الحزمة إعادة تصميم أو تعريب جميع شاشات المشروع.

أدخل مفاتيح المزوّدين من صفحة Settings بعد تسجيل الدخول؛ تُحفظ في `/data/config.toml` بصلاحيات مقيدة. بعد تغييرها، أعد تشغيل الخدمة لاعتمادها في عمليتَي API وWebUI معاً. لا تُحفظ المفاتيح في صورة Docker أو المستودع. تبقى إعدادات النشر التلقائي في حالتها الافتراضية المعطلة إلى أن تفعلها من حسابك.

## اختبار القبول بعد النشر

1. افتح الرابط في نافذة خاصة: يجب أن يطلب تسجيل الدخول. ينطبق ذلك أيضاً على `/docs` وروابط ملفات الفيديو.
2. افتح `/healthz`: النتيجة `ok` عندما تكون الواجهة وAPI جاهزتين.
3. أنشئ فيديو قصيراً بنص ومقطع محلي، ثم تحقق من التشغيل والتنزيل والموسيقى والترجمة العربية.
4. أضف مزوّد النص ومزوّد المقاطع، ثم اختبر المسار الكامل: موضوع ← نص ← صوت ← مواد ← ترجمة ← MP4.
5. تحقق من الصوت العربي فعلياً. إذا تعذر اتصال Edge، استخدم مزوّد TTS يدعم العربية بمفتاحك وأعد الاختبار.
6. أعد تشغيل الخدمة وتحقق من بقاء الإعدادات والفيديوهات. المهام التي تكون قيد التنفيذ أثناء إعادة التشغيل تحتاج إلى إعادة توليد؛ لا يُستأنف التوليد تلقائياً من نقطة التوقف.
7. اختبر أي مزوّد مدفوع اخترته بعد ضبط ميزانيته. لا يُعتبر النشر على قناة مفعّلاً قبل ربط الحساب والتحقق من إعدادات الخصوصية.

يشغّل Workflow «Private cloud runtime» بناء الحاوية واختبارات الدخول وAPI وWebUI وإنشاء MP4 والتحقق من حفظ الملفات بعد إعادة التشغيل. يستخدم بيانات اختبار اصطناعية دون الاتصال بمزوّدي الذكاء الاصطناعي المدفوعين. تفاصيل حالة الاختبارات والتنفيذ الفعلي متاحة في Pull Request؛ إعداد الملف لا يثبت نجاح نشر Railway.

## الحفظ والقيود التشغيلية

- تُحفظ الإعدادات والفيديوهات وملفات الرفع والنماذج المؤقتة على Volume. فعّل النسخ الاحتياطي من مزوّد الاستضافة وفق احتياجك.
- ملفات الخطوط والموسيقى المرفقة مدمجة في الصورة. أضف الخطوط الجديدة إلى مصدر الصورة لإبقائها عند تحديث الإصدار؛ ارفع موسيقاك عبر الواجهة لحفظها في مساحة التطبيق الدائمة.
- لا تستخدم عدة نسخ تشغيل متزامنة لهذه الحزمة؛ إعدادات المشروع وحالته مصممة أساساً لمستخدم واحد.
- WebUI وAPI يديران المهام في عمليتين منفصلتين؛ تابع مهمة API عبر API ومهمة WebUI عبر واجهتها.
- راقب استهلاك المساحة والذاكرة مع الفيديوهات الطويلة. نقطة البداية هي مهمة API واحدة في الوقت نفسه؛ لا تشغّل توليداً متزامناً من عدة واجهات على خادم صغير.
- الاستضافة واستخدام المزوّدين لهما تكاليف مستقلة، تُراجع من حساباتك قبل التفعيل.
